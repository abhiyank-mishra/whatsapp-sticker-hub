## 🛠️ Update / Reload Kaise Karein? (Chrome / Brave / Edge)

Agar aapne extension pehle se load kiya hua hai:
1. Chrome me `chrome://extensions` par jayein.
2. **WhatsApp Sticker Hub** card par **"Reload" (🔄)** icon par click karein.
3. WhatsApp Web tab par switch karein aur extension icon par click karein.
4. Saare real TMKOC stickers aur naya **"📥 Import Pack"** tab turant active ho jayega!

## 🚀 Kaise Use Karein?

### Sticker.ly Pack Import Karna:
1. Extension icon par click karke **"📥 Import Pack"** tab par jayein.
2. Code enter karein: `AKB5VR` (ya koi bhi Sticker.ly code / link).
3. **"📥 Import Entire Pack Now"** par click karein.
4. Kuch hi seconds me poora pack aapke Stickers me add ho jayega!

### WhatsApp Web se 1-Click Send Karna:
1. `web.whatsapp.com` me koi bhi chat open karein.
2. Bottom-right me green sticker icon click karein (ya **`Alt + S`** dabayein).
3. Kisi bhi sticker par click karein — wo turant chat me drop & send ho jayega!
